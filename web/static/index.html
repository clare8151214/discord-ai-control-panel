情境生圖

依照對話情境生成圖片，並用基準圖維持角色一致性。

選用

需要 ComfyUI、NoobAI、IP-Adapter 與 CLIP Vision。開啟後可設定 API 並檢查依賴。

目前僅使用文字、記憶與語音功能。已有生圖設定會保留，關閉期間不會連接生圖服務。

ⓘ

這些依賴必須安裝在「ComfyUI API 所在的電腦」。使用遠端生圖時，這台 EXE 電腦不必安裝它們；工作台會檢查，不會自動下載或安裝。

可先儲存設定；啟動生圖 Bot 前，必須通過依賴檢查。

安裝檢查只確認 API、模型選單與節點，不會實際生成圖片或驗證權重完整性。
